# BLUEWARD 0.1.1

BLUEWARD 0.1.1 убирает скомпилированный baseline ресурсов. Лаунчер сам определяет установленную ревизию, выбирает подходящий манифест и оставляет самообновление независимым от наличия патча.

## Механизм

- Локальная ревизия — наибольшее числовое значение из `AzurPromiliaJP_Data\StreamingAssets\.res\<pkg>\0release_<pkg>_<rev>.version` (builtin) и `AzurPromiliaJP_Data\.res\<pkg>\ManifestFiles\0release_<pkg>_<rev>.bytes` (delta). На builtin `3075915` плюс delta `3273853` результат — `3273853` из delta.
- Последний манифест запрашивается из `releases/latest/download/manifest.json`. Если его `patch.resource_revision` отличается от локальной ревизии, лаунчер запрашивает `releases/latest/download/manifest-<revision>.json`.
- 404 на манифест ревизии — обычное состояние «патча нет»: `Патч для ревизии <rev> ещё не выпущен`; установка выключена, игра не тронута, блок лаунчера всё равно применяется.
- `patch.files[]` — единственный источник путей, размеров и хешей. Скомпилированной таблицы целей и проверки равенства ревизии нет.
- Gate B по-прежнему требует совпадения всех пяти before-размеров и SHA-256 до первой записи; при несовпадении игра остаётся нетронутой и выводится сообщение с подставленной ревизией.
