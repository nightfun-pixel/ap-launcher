# BLUEWARD 0.1.4

BLUEWARD 0.1.4 добавляет кнопку «Играть» в состоянии «установлено». Патч `2026.11.28-4` чинит
startup-бандл, чтобы переведённый клиент доходил до титульного экрана.

## Что изменилось

- После успешной установки главная карточка показывает `Играть` основной кнопкой. Она запускает
  `AzurPromiliaJP.exe` с официальным параметром `-start=azurpromilia_launcher` из настроенной папки
  игры. «Вернуть оригинал» и «Переустановить перевод» остаются во втором ряду.
- Startup-payload пересобирается с оригинальными сжатием и шифрованием UnityFS. Прошлая сборка
  принудительно ставила LZMA/encrypted-блоки в бандл, который загрузчик игры ожидал в исходном
  формате, и клиент падал с `起動画面の読み込みに失敗しました。`.
- Патч `2026.11.28-4` меняет только `startup.r` относительно r3; `vstring.bytes`, `static-text.r`,
  `table_data.bytes` и `onest-font.r` сохраняют выход r3.

## Обновление

0.1.2 и новее обновляются до 0.1.4 сами. Версии 0.1.1 и старше не проходят редирект
`release-assets.githubusercontent.com` и требуют одной ручной загрузки 0.1.4. Патч r4 выбирается
через `manifest-3273853.json`; совместимый `manifest.json` сохраняет блок r1 `patch-3219598` для
bootstrap 0.1.0.

## Проверка

- `build.cmd`: 875 проверок, 0 failed; CTest `core` проходит.
- Пересобранный `startup.r` сохраняет исходные флаги `UnityFS` и блоки LZ4HC; CRC32 сбалансирован
  под исходный слот.
- Ручная установка r4 на клиент 3273853 доходит до русского титульного экрана
  (`Начать путешествие`); процесс игры остаётся живым, ошибки startup-бандла в журнале нет.
- Пять пар before/after и размер ZIP не изменились; от r3 отличается только startup-payload.
