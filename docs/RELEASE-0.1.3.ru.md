# BLUEWARD 0.1.3

BLUEWARD 0.1.3 исправляет строку атрибуции в настройках и обновляет проверки исходников и
документацию. Работа с патчем, схема манифеста и пять payload-файлов r3 не изменились.

## Что изменилось

- Строка «О программе» в настройках называет `Yostar` и `Manjuu Co., Ltd.`.
- Сканирование исходников проверяет, что продукт не обращается к хосту GitHub API и не содержит
  закомпилированной ревизии ресурсов.
- Страница пробелов тестов описывает публичный релиз и редирект на
  `release-assets.githubusercontent.com`.

`release-assets.githubusercontent.com`, поэтому им нужно один раз скачать 0.1.3 вручную.
