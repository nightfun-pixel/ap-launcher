## Хостинг

Репозиторий и его релизы публичные; анонимные запросы `manifest.json`, `manifest-3273853.json` и `BLUEWARD.exe` возвращают HTTP 200. GitHub отдаёт ассеты релизов через `release-assets.githubusercontent.com`; 0.1.2 следует этому редиректу, а 0.1.1 и старше его отклоняют и требуют однократной замены вручную.

## Пробелы реального клиента

- Локальная игра содержит builtin `3075915` и delta `3273853`; определение даёт `3273853`. `manifest-3273853.json` и `patch-3273853` опубликованы; установка и возврат на игре ещё не приняты.
- Реальный архив 233 942 380 байт, цепочка редиректов GitHub и поддержка Range (T-048, T-055, T-076) не проверялись; только loopback-эквиваленты.
- Пять целей не проверены запущенной игрой; поведение ACE/repair неизвестно. Не запускайте приёмку, пока выполнен вход в игру.
