# Атрибуция

BLUEWARD содержит один сторонний программный компонент и один визуальный ресурс. Официальная релизная сборка дополнительно встраивает фоновый клип, который в дереве исходников не распространяется.

## Код

| Компонент | Версия | Расположение | Лицензия |
| --- | --- | --- | --- |
| miniz | 2.2.0 | `third_party/miniz/` | MIT |

Полный текст MIT — в `third_party/miniz/LICENSE`. miniz используется только для распаковки raw DEFLATE внутри читателя ZIP-патча (`src/core/zip.cpp`); разбор ZIP, CRC-32, проверка имён и извлечение — код BLUEWARD.

Другой сторонний исходный код не вендорится. Лаунчер использует только системные библиотеки Windows: D3D11, DXGI, Direct2D, DirectWrite, DWM, WIC, Media Foundation, WinHTTP, BCrypt, ZIP через miniz, Shell, COM.

## Визуальные ресурсы

| Ресурс | Происхождение | Условия |
| --- | --- | --- |
| `res/blueward.ico` | Оригинальная марка BLUEWARD, созданная для проекта | Ресурс проекта; не происходит от игровых или донорских иконок |
| Фоновый клип (только релизная сборка; в репозитории не хранится) | Официальное hero-видео японского сайта Azur Promilia, обрезано и перекодировано в 1280×720, 30 fps, H.264 High, без звука | © Manjuu Co., Ltd. Все права защищены. © Yostar, Inc. Все права защищены. См. ниже |

Японский гайдлайн по вторичному творчеству разрешает некоммерческие фанатские работы, но исключает прямой копирующий перенос официальных материалов. Фоновый клип — официальный промо-материал, а не фанатский ресурс. Он встраивается только в релизную сборку оператора; в дереве исходников его нет. Не распространяйте клип или сборку с ним без разрешения Yostar/Manjuu. Одной атрибуции недостаточно для лицензии.

Интерфейс использует системный Segoe UI; файл шрифта не поставляется. Донорские иконки, клипы, шрифты, скриншоты, логотипы игры и мастер-арт отсутствуют.
