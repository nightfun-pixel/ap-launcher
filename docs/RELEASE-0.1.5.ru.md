# BLUEWARD 0.1.5

BLUEWARD 0.1.5 поддерживает патч r6 из семи payload-файлов и запускает игру прямо из состояния
«установлено». Патч r6 исправляет полноширинную кириллицу без изменения размера проверяемых
лаунчером font-бандлов.

## Что изменилось

- Манифест принимает пять старых или семь текущих payload-файлов. Новые файлы — `font-a00.r` и
  `font-b00.r`, внешние TMP fallback-бандлы.
- Патч `2026.11.28-6` переписывает метрики `hmtx` для 67 кириллических глифов в обоих бандлах:
  `advance = (xMax - xMin) + 2 * round(upm * 0.055)`, `lsb = round(upm * 0.055)`. Пробельные
  глифы не тронуты. TTF и UnityFS-бандл сохраняют исходный размер; CRC32 сбалансирован. Проверка
  размеров официального лаунчера остаётся чистой.
- `startup.r` пересобран с тем же размером и указывает `ast_b00_origin_SDF` на MiSans Font `b00`
  внутри архива. `onest-font.r` остаётся байт-в-байт оригинальным.
- В установленном состоянии появляется `Играть`; кнопка запускает `AzurPromiliaJP.exe` с
  `-start=azurpromilia_launcher` из настроенной папки.
- **Рисунок** MiSans в этот патч не входит: hmtx-фикс оставляет контуры OT-Shin Maru, но делает
  их пропорциональными. Size-preserving subset MiSans — следующий шаг.

## Обновление

0.1.2 и новее обновляются до 0.1.5 сами. Версии 0.1.1 и старше не проходят редирект
`release-assets.githubusercontent.com` и требуют одной ручной загрузки 0.1.5. Перед установкой r6
восстанови пять файлов игры и два внешних font-бандла: Gate B сверяет истинные
`before_size`/`before_sha256`.

## Проверка

- `build.cmd`: 882 проверки, 0 failed; CTest `core` проходит.
- `font-a00.r` и `font-b00.r` сохраняют исходные размеры (4 517 899 и 4 550 495) и CRC32; меняются
  только advance кириллицы.
- `startup.r` сохраняет размер 58 707 878 байт; `ast_b00_origin_SDF` указывает на MiSans Font.
- `checkStat` официального лаунчера сравнивает только размеры; все проверяемые файлы сохраняют
  официальные размеры. Полное восстановление использует CRC-64 и заметит `startup.r`; не запускай
  полное восстановление на пропатченном дереве.
