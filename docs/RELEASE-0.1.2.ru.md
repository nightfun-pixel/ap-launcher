# BLUEWARD 0.1.2

BLUEWARD 0.1.2 возвращает скачивание после переноса релизных ассетов GitHub на
`release-assets.githubusercontent.com` и перестаёт считать отсутствие последнего манифеста
сетевой ошибкой.

## Что изменилось

- Allowlist редиректов принимает ровно хосты `github.com`, `objects.githubusercontent.com` и
  `release-assets.githubusercontent.com`. По-прежнему обязательны HTTPS, порт 443, отсутствие
  userinfo, фрагмента и IP-литерала; похожий хост вроде
  `release-assets.githubusercontent.com.evil` отклоняется.
- Ответ 404 или 410 на `releases/latest/download/manifest.json` переводит запрос на
  `manifest-<localRevision>.json`. Если и этого файла нет (404/410), лаунчер показывает обычное
  состояние `Патч для ревизии <rev> ещё не выпущен` и ничего не пишет. Сбои транспорта, TLS и 5xx
  остаются `E_NET`.
- В карточке ошибки основная кнопка получает отдельную строку на всю ширину, поэтому
  `Установить / Обновить перевод` читается целиком при 1100×720, а не обрезается двухколоночной
  сеткой.

## Обновление

Версии 0.1.1 и старше не умеют следовать редиректу на `release-assets.githubusercontent.com`,
поэтому их самообновление падает с `E_NET`. Скачайте 0.1.2 один раз вручную. Начиная с 0.1.2
самообновление идёт через новый хост.
